    4. 4PayPalCapture, keep holding, or void.

      Add it to your checkout

      Put the check right before your PayPal capture call. Use the amount from the PayPal order, and the Lowtides server you trust, never the URL written inside the pass.

      // npm-free ES module: integrations/merchant-check/lowtides-pass-check.js
import { checkPass } from "./lowtides-pass-check.js";

const order = await paypal.getOrder(orderId);              // your PayPal client
const v = await checkPass({
  pass: req.body.lowtidesPass,                             // sent by the agent
  amount: Number(order.purchase_units[0].amount.value),     // from PayPal, not the agent
  merchant: "Acme Data", category: "data",
  verifyUrl: "https://lowtides.ai/v1/pass/verify",          // the server you trust
});
if (v.decision === "capture") await paypal.captureOrder(orderId);
else if (v.decision === "refuse") await paypal.voidAuthorization(authId);
// "hold": keep the order open until the owner approves in Lowtides
console.log(v.label, v.reasons);

      What one check covers

      A PayPal approval proves the buyer said yes once. The pass tells you the agent is still allowed to, right now.

      Genuine

      Ed25519 signature, checked offline. A changed limit or forged pass is refused.

      Not revoked

      Stop all, STOP, a loop-guard pause or the owner's Revoke show up at once.

      Inside the limits

      Per purchase, today's total, approval line, blocked categories and merchants, hours.

      Fails closed

      Lowtides unreachable? The answer is hold, so nothing is captured on a guess.

      Why merchants care: a runaway or hijacked agent turns into refunds, disputes and chargebacks for you. Checking the pass first means you only take money its owner still allows, and you have a signed record of the permission you relied on.

      Questions

      Why should a merchant check an AI agent's pass?

      A PayPal approval only proves the buyer approved the order at that moment. The Lowtides Pass tells you whether the agent is still allowed to spend this amount at your store right now, and whether its owner pressed Stop all. That cuts disputes and chargebacks from runaway or hijacked agents.

      When should I check the pass?

      Right before you capture the PayPal order or authorization, using the amount from the order itself, not a number the agent tells you.

      What if Lowtides is down?

      The checker fails closed: the answer is hold, so nothing is captured until the check succeeds.

      Does checking a pass cost money or record anything?

      No. POST /v1/pass/verify is free, needs no login and records nothing. It runs the same checks a real spend request would and reports what would happen. More on the format: LOWTIDES-PASS.md, or paste a pass into the pass checker.
