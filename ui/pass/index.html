What is a Lowtides Pass?

A permission slip you can check

Today a merchant can't tell if an AI agent is allowed to spend. The pass says who the agent is, which Lowtides server governs it, and its live limits: most per purchase, daily limit, when a person must approve, blocked categories and merchants, and when the pass expires.

Signed, and revoked in an instant

Every pass is signed with Ed25519. Check the signature offline with the public key, or online to also see if it was revoked. Stop all, STOP and a loop-guard pause revoke it at once.

AP2-aligned. The pass follows the idea of an Agent Payments Protocol (AP2) Intent Mandate: a plain-English intent plus structured constraints. It is not an official AP2 integration.

Check one from code

curl -X POST https://lowtides.ai/v1/pass/verify \
  -H "Content-Type: application/json" \
  -d '{"pass": "PASTE_THE_PASS", "amount": 12.50, "merchant": "Acme Data", "category": "data"}'

Public keys: /.well-known/lowtides-pass-keys.json. Agents get their pass from GET /v1/pass or the MCP tool get_pass.
