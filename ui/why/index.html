How it works

Your agents don't change. Point them at Lowtides instead of the model provider, or connect it as an MCP server.

STEP 1

Type your rules in plain English

Claude turns them into strict rules you review before saving.

Max $100 a day. Ask me over $25. Never buy gift cards or crypto.
STEP 2

Agents ask before they spend

Every model call and every purchase is checked against the rules in the request path, before the money moves. Code decides. The AI never approves a payment.

STEP 3

You approve, or press STOP

Risky purchases wait for one tap. STOP ALL halts every agent, voids PayPal holds and cancels payouts that haven't landed.

Questions

What is an AI cost governor?

An AI cost governor sits between AI agents and your money and enforces limits while the agent runs. Lowtides governs both sides of agent spending: what the agent costs to run (model calls) and what it buys (purchases), under one daily budget with a STOP button.

How do I set a spending limit for an AI agent?

Type the rules in plain English, for example: "Max $100 a day. No more than $60 per purchase. Ask me over $25. Never buy gift cards or crypto." Lowtides turns them into strict rules you review, and the agent must ask Lowtides before every purchase.

Does the AI decide whether a payment goes through?

No. Claude only helps turn your plain-English rules into structured rules that you approve. Every payment decision is made by plain code against those rules, and anything risky waits for a person.

What happens when I press STOP ALL?

Every agent stops, pending purchases are denied, open PayPal authorization holds are voided and PayPal payouts that haven't been claimed yet are cancelled. The model proxy refuses further calls until a person turns the agent back on.

How does Lowtides stop a runaway agent loop?

The loop guard notices when an agent keeps sending the same or growing request and pauses it before it burns more money. Per-call cost caps, prompt-size limits and a combined daily budget catch the rest.

Which PayPal APIs does Lowtides use?

Orders v2 for wallet top-ups and authorize-then-capture holds, Payouts to pay merchants for approved purchases, Invoicing v2 to bill clients for agent usage, and Webhooks with signature verification. It can also guard the PayPal Agent Toolkit.

Does it work with my existing agents?

Yes. Point your agent at Lowtides instead of the OpenAI or Anthropic API, or connect Lowtides as an MCP server. Agents ask before buying through a simple spend API (POST /v1/spend).

Is Lowtides free?

Yes. Lowtides is open source under the AGPL-3.0 license, and the live demo uses the PayPal sandbox and simulated AI models, so nothing costs real money.
